# Procuro Quem Faça (PQF)

Marketplace de prestadores de serviço para Londrina, PR. A plataforma conecta clientes a profissionais locais e registra portfólios fotográficos, acompanhamento e avaliações de serviços reais.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Comandos

- `npm run build` — build de produção
- `npm run lint` — validação com ESLint
- `npm run test:run` — testes unitários com Vitest

Configure as variáveis do Supabase no ambiente local antes de executar o projeto.
